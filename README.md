# Tuloma illustration gallery

This repository hosts the public review gallery for Tuloma's 520 vocabulary illustrations.

Use the live gallery to search across English, Swedish, and German; filter by lesson or word type; download exact SVG files; and open a pre-filled revision issue for any concept.

The generation pipeline and internal working files live in a separate private repository. This public repository contains only the static site, final reviewable SVGs, and issue templates needed for collaboration.
